# Attention Is All You Need
## 2017

Pesquisadores do Google apresentam o **Transformer**.

Mudanças:

- paralelização
- contexto maior
- treinamento mais eficiente

É o nascimento da arquitetura utilizada até hoje.

# Pré-treinamento

Ideia simples.

1. Esconda uma palavra.
2. Peça ao modelo para descobri-la.
3. Repita isso bilhões de vezes.
4. O modelo aprende linguagem.
