# Agile Vibe Coding

A IA deixou de ser apenas um **copiloto**.

Ela passa a participar do ciclo de desenvolvimento.

Hoje é comum:

- especificar requisitos em linguagem natural;
- gerar protótipos em minutos;
- iterar conversando com a IA;
- validar resultados continuamente.

> O desenvolvedor passa menos tempo escrevendo código e mais tempo tomando decisões.

# O novo papel do programador

## Antes

Programador → Código

## Hoje

Programador → Especificação → IA → Código

## **O diferencial deixa de ser apenas escrever código.**

Passa a ser:

- entender o problema;
- definir restrições;
- validar resultados;
- tomar decisões de engenharia.
